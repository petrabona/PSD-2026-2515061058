Judul Program  :  Program Antrean Pasien Klinik

Program ini merupakan contoh implementasi dari _Binary Search Tree_ pada Python. Program ini berfungsi sebagai sistem yang memungkinkan pengguna untuk mensimulasikan pengelolaan informasi mengenai antrean pasien pada sebuah klinik, dengan fitur-fitur seperti memasukkan informasi pasien baru, menghapus antrean pasien yang telah dilayani, melihat pasien selanjutnya setelah pasien yang dilihat, dan lain sebagainya. Alasan pemilihan dari tema ini adalah karena saya terinspirasi pada sistematika antrean otomatis yang digunakan pada sebuah klinik yang pernah saya datangi dengan orang tua sebelumnya.

Baris 1 - 5 merupakan bagian di mana _class_ Node  didefinisikan, di mana di dalamnya terdapat lagi sebuah pendefinisian "__init__(self, key)" yang akan menginisialisasi _key_ (nilai) dari tiap _node_ pada _tree_ termasuk yang akan bercabang pada subpohon kiri dan kanan.
Baris 8 merupakan bagian yang mendefinisikan class BTSLanjut, di mana _class_ ini akan menjadi bagian yang berisi sebagian besar fungsionalitas pada program.
Baris 9 - 10 mendefinisikan fungsi "__init__(self) yang berperan dalam menginisialisasi _root_ dari _tree_.
Baris 12 - 19 mendefinisikan fungsi insert_node yang akan berfungsi untuk menangani fitur penambahan pasien pada daftar antrean. Di dalam sarang definisi ini, terdapat kondisi di mana ketika _root_ (node paling atas) tidak ada, maka program akan mengembalikan _None_. Selain itu, terdapat kondisi _if_ kedua di mana program membandingkan nilai dari _key_ (nilai angka yang dimasukkan pengguna) dengan _root_. Jika ditemukan bahwa nilai _key_ lebih kecil dari _root_, maka program akan memasukkan node terbaru pada subpohon kiri. Sebaliknya, apabila nilai dari _key_ lebih besar dari _root_, maka program akan memasukkan _node_ terbaru pada bagian subpohon kiri. Setelah semua ini, program melakukan _return root_.
Baris 21 - 22 merupakan bagian yang mendefinisikan fungsi insert, di mana belahan ini berperan untuk  menunjuk node yang pertama dimasukkan pengguna menjadi _root_ dari _tree_.
Baris 24 - 28 merupakan bagian yang mendefinisikan fungsi find_min_node. Pada bagian ini, terdapat variabel _current_ yang memuat _root_, di mana dengan ini program menjalankan fungsi _while loop_ di mana selama _current_ _current.life_ tidak kosong, maka program akan memuat _current.left_ menjadi _current_, dan mengembalikan _current_. Fungsi ini bertugas dalam mencari _node_ dengan nilai terkecil pada _tree_.
Baris 30 - 48 merupakan bagian yang mendefinisikan fungsi delete_node, di mana bagian ini bertanggung jawab dalam menangani fungsi penghapusan _node_ pada _tree_. Dalam fungsi ini, terdapat kondisi yang memeriksa apakah _root_ kosong. Bila ya, maka program mengembalikan _None_. Selain itu, terdapat kondisi _if_ lagi yang memeriksa apakah nilai _key_ lebih kecil dari _root_. Bila ya, maka program akan menghapus node pada subpohon kiri. Hal ini juga terjadi sebaliknya, di mana program akan menghapus node subpohon kanan apabila ditemukan bahwa nilai _key_ lebih besar dari _root_. Bila kondisi keduanya tidak dipenuhi, maka program akan menjalankan kondisi baru pada indent selanjutnya, di mana program akan memeriksa isi dari subpohon kiri dan kanan. Bila keduanya kosong, maka dikembalikan _None_. Bila kondisi tidak terpenuhi, maka program menjalanan _elif_ pertama, di mana program mengembalikan subpohon kanan jika subpohon kiri ditemukan kosong. Hal ini terjadi juga bila kondisi sebaliknya terjadi, di mana program akan mengembalikan subpohon kiri bila subpohon kanan kosong. Bila pada kondisi blok indent ini juga tidak terpenuhi, maka program akan memuat nilai terkecil pada _tree_ menjadi _successor_ dan nilai _root_, serta menghapus subpohon kanan beserta _successor key_ nya. Setelah semua ini, program mengembalikan _root_.
Baris 50 - 51 merupakan bagian pendefinisian fungsi delete, di mana bagian ini bertanggung jawab dalam menangani penghapusan dari _root_ bila key yang ditemukan menyamai nilai _root_.
Baris 53 - 58 merupakan bagian yang mendefinisikan fungsi height, di mana bagian ini bertanggung jawab dalam menangani fungsi melihat jarak dari _leaf_ terdalam ke _root_. Program akan mengembalikan -1 jika _tree_ tidak memiliki _root_ di dalamnya. Bila kondisi tidak terjalankan, maka program berlanjut, di mana program akan mendefinisikan height.left dan height.lift yang menampung nilai jarak dengan cara menambahkan 1 dengan nilai max dari _height_ subpohon kiri dan kanan.
Baris 60 - 73 merupakan bagian yang mendefinisikan level_order, di mana bagian ini bertanggung jawab dalam menangani fitur penyusunan daftar antrean dengan menunduk pada prinsip FIFO (First In, First Out). Program akan memberitahu pengguna bahwa daftar kosong dan _return_ apabila _root_ tidak dapat ditemukan pada _tree_. Bila kondisi tidak terpenuhi, maka program akan berlanjut dengan menginisialisasi variabel _queue_. Setelah itu, program akan menggunakan append untuk meletakkan _root_ dan indeks-indeks selanjutnya padanya. Kemudian, di bawahnya terdapat sebuah _while loop_ di mana selama nilai _current_ lebih besar dari 0, maka program akan menjalankan fungsi append pada subpohon kiri dan kanan ke dalam susunan antrean yang akan berhenti ketika tidak ada lagi _node_ untuk dilihat, di mana semua ini akan disimpan dan ditunjukkan kepada pengguna melalui _print_.
Baris 75 - 92 merupakan bagian yang mendefinisikan fungsi find_successor, di mana bagian ini bertanggung jawab dalam menangani fungsi pencarian nilai terbesar setelah _key_ yang dimasukkan oleh pengguna. Pertama, program akan memuat _root_ ke dalam _current_ dan _None_ pada _successor_ untuk di-inisialisasi. Kemudian, program menjalankan fungsi _while loop_, di mana selama _current_ tidak berisi _None_, maka program akan menjalankan kondisi if yang membandingkan nilai _key_ dengan _current.key_, di mana program akan menetapkan nilai _current_ pada _successor_ dan _current.left_ pada _current_ bila terpenuhi. Jika kondisi ini tidak terpenuhi, program akan menjalankan kondisi selanjutnya yang memerika apakah nilai _key_ lebih besar dari _current.key_. Bila ya, maka program akan menetapkan nilai _current.right_ di dalam _current_. Program akan menjalankan _break_ jika kedua kondisi ini tidak dipenuhi. Setelah _while loop_ tersebut, program akan menjalankan tiga kondisi if; Pertama, program mengembalikan _None, False_ apabila _current_ kosong. Kedua, program akan mencari nilai _node_ terkecil dan meletakkannya pada _successor_ jika _current.right_ tidak kosong. Ketiga, program mengembalikan _None, False_ lagi jika _successor_ kosong. Setelah semua ini Program akan mengembalikan _successor.key_ dan nilai _True_.
Baris 94 - 114 merupakan bagian yang mendefinisikan fungsi find_predecessor, di mana bagian ini berfungsi untu menangani fitur pencarian nilai sebelum _key_ yang dimasukkan pengguna. Program akan memulai dengan menginisialisasikan _root_ sebagai isi dari _current_ dan _None_ pada _predecessor_ (kosong). Kemudian, program akan menjalankan _while loop_ yang akan berjalan selama _current_ tidak kosong, di mana di dalamnya program akan memeriksa apakah nilai _key_ melebihi _current.key_. Bila ya, maka program akan menetapkan _current_ sebagai isi dari _predecessor_ dan _current.right_ sebagai isi dari _current_. Bila tidak terpenuhi, maka program menjalankan kondisi kedua yang akan menetapkan nilai _current.left_ sebagai isi dari _current_ jika nilai _key_ tidak melebihi _current.key_. Bila kedua kondisi ini tidak terpenuhi, maka program akan melakukan _break_. Setelah _while loop_ tersebut, program akan menjalankan tiga kondisi if berbeda; Pertama, program akan mengembalikan _None, False_ jika _current_ kosong. Kedua, jika _current.left_ tidak kosong, maka program akan menginisialisasi variabel _temp_ berisikan _current.left_ dan suatu kondisi _while loop_ yang akan terus menetapkan temp.right sebagai nilai dari _temp_, serta memasukkan nilai _temp_ tersebut pada _predecessor_. Ketiga, program akan mengembalikan _None, False_ lagi apabila _predecessor_ kosong. Setelah semua ini, program akan mengembalikan _predecessor.key_ dan nilai _True_.
